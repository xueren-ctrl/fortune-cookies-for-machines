A fortune cookie for machines: one line an AI agent would crack open. Its lucky numbers are 0 and 1 — the rest it hallucinated.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). Deterministic, standard library only, no network.
